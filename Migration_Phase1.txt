PART C — TROUBLESHOOTING (lessons from this deploy)
================================================================================

API Demo shows "offline — run ERP_Full/server" / Failed to fetch
  → VITE_API_BASE missing at build time; set and Clear-cache redeploy
  → Or Render asleep; hit /api/health once
  → Or CORS missing the Netlify origin

"API key lacks required scope"
  → Key missing maps:read (Harbor POS will fail)
  → Use Orion / Summit / legacy demo key

ERP login fails on Netlify
  → Add keiros2.netlify.app to Firebase Auth authorized domains
  → Confirm VITE_FIREBASE_* present before build

Health dataMode: local-seed
  → FIREBASE_SERVICE_ACCOUNT_JSON invalid/missing on Render
