# Keiros Tour App — User Manual

This manual is for a visitor taking a self-guided tour, and for the person at the desk who hands out the code.

You join with a code from the property. The app then walks you in, floor by floor, at your own pace. There is no guide on the tour.

The property prepares the map and the code in Keiros ERP. You only need this app.

## 1. Before you start

You need:

- The Keiros Tour App open on your phone.
- The tour code from the property. It is printed as a QR code at the lobby, the leasing desk, or a model door. You type the code into the app. If your phone camera copied the link from the QR, you can paste that link instead. The app does not open its own camera.
- A connection while the tour is loading and while directions are requested.

Location is optional. On the second screen you can allow it or skip it. Visit timing, which records how long you stand at a stop, stays off until you turn it on during the walk.

A code looks like `OC-CHI-2026`. Use the code on the sign. **Use demo scan** on the code screen fills in a practice code. Use that only when the desk tells you this property is on the demo.

## 2. Join the tour

### Begin

The first screen says **Keiros** and **Self-guided property tour**.

Choose **Begin my tour**.

You do not create an account and you do not enter a password.

### Allow location, or skip it

The next sheet is **Help us guide you**. It lists:

- **Location** — where you are on the property.
- **Directions** — the path from stop to stop.
- **Visit timing** — optional. You can turn this on later.

Choose **Continue** to let the phone ask for location, then move on. The button reads **One moment…** while the phone answers. If the phone shows its own permission question, choose Allow or Don’t Allow. Either way, the tour continues.

Choose **Continue without location** if you do not want the phone to use location. You can still follow the directions.

The back arrow returns to the first screen.

### Enter the code

The sheet is **Join this property tour**.

1. Tap **Tour access code**.
2. Type the code from the sign. Letters are capitalized as you type. Or paste the link your camera copied from the QR.
3. Choose **Start with this code**.

The button stays off until the field has something in it. It reads **Opening tour…** while the code is checked.

**Use demo scan** fills the practice code. It does not open a different property.

If the code is refused, the reason appears in red under the field. Check the spelling. If it matches the sign, ask the desk for a current code.

The back arrow returns to the location screen.

### Wait for the tour to open

Two screens pass on their own. Do not close the app.

1. **You’re in** shows a check mark, the property name, and the address, then **Preparing your self-guided tour…**
2. **Getting ready** shows a progress bar and a line that moves through:
   - Opening your property tour…
   - Loading floors & spaces…
   - Gathering amenities & highlights…
   - Lining up your tour stops…
   - Preparing indoor guide…
   - Tour ready

When the bar finishes, the welcome screen opens.

If the bar sits still, check your connection, then go back and enter the code again.

## 3. Choose how to walk

The welcome screen is titled **Tour** and the property name. The card shows the code, the city, how many buildings there are, and how many places there are.

Three notes on the screen:

- **Enter once** — get inside first.
- **Lowest floor first** — see every place on a floor, then go up.
- **End anytime** — you can leave before the last stop.

Choose one:

- **Start self-guided tour** builds the walk for you. The first stop gets you inside. After that, stops run from the lowest floor to the highest. On each floor you see the homes and amenities on that floor before the next floor up. Stairs, elevators, and corridors are used for directions. They are not listed as stops.
- **Browse places instead** lets you pick one home or amenity yourself.

If you see **We couldn’t load the property map**, choose **Retry**. You need a connection for this step. If retry keeps failing, the desk needs to check that the map is published.

The back arrow leaves the welcome screen.

### Follow the prepared list

After **Start self-guided tour**, the screen is **Floor by floor**.

- The top line says **Self-guided** and about how many minutes the walk takes.
- Stops are grouped by floor. **Floor 1** in the list is the lowest floor, which may not be labeled “1” on the building sign. Each group shows the floor name and how many stops are on it.
- The first stop says **Enter here**. Later stops are numbered. A stop you have already opened says **Seen**. The one you are on says **Up next**.
- Tap a stop to select it.
- The button at the bottom reads **Head to** and the stop name. It reads **Getting directions…** while the path is requested, and **Choose a stop** until you tap one.

Two tabs sit at the top once a list exists:

- **My tour** is this floor-by-floor list.
- **Explore map** is the search described next.

### Pick a place yourself

This is what you see after **Browse places instead**, and when you open **Explore map** during a guided tour.

- Search with **Search homes or amenities**.
- Filter with **All**, **Homes**, **Gym**, **Pool**, **Club**, or **Parking**.
- Tap a card to select it. The card shows the name, the building, and the floor.
- Choose **Head to** and the place name.

**No matches — try another filter** means the search or the filter is too narrow. Clear the search or choose **All**.

If a place you expect is missing, it is not on the map the property published. Tell the desk the name of the place.

### Read the approach before you walk

After directions load, you see a map and a short summary.

- First stop of a guided tour: **Step 1 · Get inside**, with **Arrive**, **Walk in**, and **Enter**.
- A later guided stop: **Inside · Place** and the count, with **Already inside**, **Walk to place**, and **Explore**.
- A place you picked from search: **Next on your tour**.

Three times are shown:

- **To parking** — minutes to the arrival point.
- **To entrance** — minutes on foot to the door. A dash means this route has no separate walk to the door.
- **Inside** — minutes indoors.

Under that, you may see the weather, the temperature, and how many indoor checkpoints are on the route.

Choose **Continue to this stop**. The back arrow returns to the list without starting the walk.

## 4. Follow the directions

This is the walking screen. A banner shows the current instruction, the remaining feet, the remaining minutes, and which tip you are on (for example tip 2/6).

The bottom of the screen has **Previous** and a forward button. The forward button changes as you go:

| The button says | What it does |
| --- | --- |
| **Next** | Moves to the next direction while you are still outside. |
| **Next place tip** | Moves to the next direction inside the building. |
| **Next:** and a place name | You finished the directions for this stop. The app loads the next stop and keeps you inside. |
| **Finish building tour** | You finished the last stop. The app opens the door screen. |

**Previous** goes back one direction. It is unavailable on the first direction.

### While you are still outside

- **Outside** shows the street map.
- **Inside** shows the building.
- Tap **Arrive**, **Walk in**, or **Explore** to jump to that part of the route.
- **Weather** and **Traffic** describe the approach. **Refresh** updates them.
- A chip reads **Lowest floor first** and the number of stops.

### After you are inside

The app switches to the building view and opens the list of places.

- The top chip reads **Floor by floor**.
- **End tour** is at the top and again near the bottom. It leaves the walk and opens the door screen. You do not have to finish every stop. It does not skip the door screen.
- **Up next on your walk-through** names the following stop.
- **Places inside** is the indoor part of the route.
- **Show units** opens the list. **Hide list** closes it.
  - **All** shows every floor.
  - A floor chip shows one floor.
  - **Go** routes you to that place. The place you are already on says **Current**.
  - **No places on this floor** means that floor has nothing to visit on the map.
  - **Updating route…** means the new path is still loading.
- A chip shows which floor you are on and which unit this is on that floor.

You stay on this screen as each new stop loads. You return to the stop list only if the next path cannot be planned. The message then tells you to try again.

### Direction tips

**Direction tips** opens the full list of steps. **Hide tips** closes it. Tap a numbered step to make it the current instruction.

Drag the handle on the bottom sheet to collapse it or open it again.

The back arrow returns to the approach map.

### Time at a stop

Shortly after navigation opens, a prompt asks **Track time at each stop?**

- **Enable** starts a timer. The panel then says **You’re spending time here**, names the place, and counts minutes and seconds. The line under it says **optional visit timing**. If the phone cannot reach the property’s system, it says **couldn’t sync quietly**. Keep walking. The tour does not stop.
- **Later** closes the prompt. Timing stays off.

This is optional. The desk can see the times only if you choose Enable.

## 5. Open a door

You reach this screen when you choose **End tour**, when you choose **Finish building tour**, or when a stop you picked yourself is finished.

The sheet is titled **Almost done**. If you visited stops, it says how many. Otherwise it says the unlocks are optional.

The list can include:

- Main Lobby
- Fitness Center
- Pool Deck
- Resident Parking Gate
- Clubhouse

Each row says **Guest access**. Choose **Unlock** on the door you need.

- **Unlocked** means you have temporary access. The message includes the time it lasts, about 15 minutes.
- **Unavailable** means the door was not opened. The parking gate may say access was denied and that visitor parking needs approval at the front desk. Go to the desk for that gate. You can still unlock a different door, or skip them all.

Choose **Wrap up my tour** when you are done. You do not have to unlock anything.

The back arrow returns to the directions if you are not ready to finish.

## 6. Rate the visit and leave

### Tour complete

You see:

- **Stops seen** — how many you opened.
- **On your list** — how many were on the guided list.
- **Tour time** — about how long the visit was.
- A checklist. A check mark is a stop you saw. An open circle is one you did not.

**How was this self-guided tour?** Tap one to five stars. Five is already selected. Then choose **Submit & finish**. The button reads **Saving…** while it sends.

### Thanks for visiting

The title changes to **Thanks for visiting** and the screen says **We saved your feedback.**

Choose **Tour another property** to start over and enter a different code. Closing the app also ends the visit.

## 7. When something does not work

| What you see | What to do |
| --- | --- |
| **Start with this code** stays off | Type a code, paste the link from the QR, or choose **Use demo scan** only if the desk said to use the practice code. |
| A red message under the code | Read the code on the sign again. If it matches, ask the desk for a current code. The old one may be expired or turned off. |
| **Opening tour…** does not finish | Check the connection. Go back and submit the code again. |
| **We couldn’t load the property map** | Choose **Retry**. If it fails again, tell the desk. The map may not be published. |
| **Getting ready** never reaches **Tour ready** | Stay on the screen on a stable connection. If it is stuck, close the app and enter the code again. |
| **No matches — try another filter** | Clear the search and choose **All**. |
| **No places on this floor** | Choose another floor, or **All**. |
| The bottom button says **Choose a stop** | Tap a stop or a place card first. |
| **Getting directions…** or **Updating route…** lasts a long time | Wait, then go back and choose the stop again. If it keeps failing, tell the desk which two places you were trying to join. |
| **That place isn’t on the tour map yet.** | Pick another place. That one is not on the published map. |
| **couldn’t sync quietly** | Timing could not be sent. Keep walking. The timer on the phone still runs. |
| The parking gate asks for the front desk | That door needs staff approval. Ask the desk. Other doors can still unlock. |
| **Unavailable** on another door | The property has not opened that door for guests. Choose **Wrap up my tour** anyway. |
| You ended sooner than you meant to | **End tour** opens the door screen. You can go back from there. After **Wrap up my tour**, the walk is finished. Start again with the same code if the desk says the code can be reused. |

## 8. For the person at the desk

Hand the visitor the printed QR or read them the code. They type it, or they paste the link if their camera copied it. They do not scan from inside the app.

Tell them:

1. Choose **Begin my tour**.
2. Choose **Continue** if they are comfortable sharing location, or **Continue without location**.
3. Enter the code and choose **Start with this code**.
4. On the welcome screen, choose **Start self-guided tour** unless they already know the one place they want.
5. Follow **Next** until the button names the next place. They can choose **End tour** whenever they want. That opens optional door unlocks, then the star rating.

Before you print a code, confirm in Keiros ERP that the property has a live map and that the code is Active and not past its date. Put the QR at the lobby, the leasing desk, or the model door.

After the visit, look in Keiros ERP:

| The visitor did this | Open this |
| --- | --- |
| Entered the code | Code Usage, or Mobile Sessions |
| Downloaded the tour | Map Downloads |
| Followed directions | Journey Tracking |
| Turned on visit timing | Dwell-Time |
| Submitted stars | The feedback saved at the end of that visit |

If many people fail on the code screen, check that the code is Active. If they get in and the map is empty, publish the map and, on Map Downloads, force a sync for phones that already downloaded the old one. If every door says Unavailable, check the door readers in the ERP. The visitor cannot override that from the phone.
