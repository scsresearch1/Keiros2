------------------------------------------------------------------------------
STEP 1 — Deploy API on Render
------------------------------------------------------------------------------
1. Open https://dashboard.render.com → New → Web Service
   (or New → Blueprint and select render.yaml from the repo)

2. Connect repository: scsresearch1/Keiros2

3. If manual Web Service (not Blueprint), set:
   - Name: keiros-erp-api
   - Root Directory: ERP_Full/server
   - Runtime: Node
   - Build Command: npm install
   - Start Command: npm start
   - Instance: Free is OK for demo (spins down when idle)

4. Environment variables (Render → Environment):

   NODE_ENV=production
   FIREBASE_PROJECT_ID=<your Firebase project id>
   FIRESTORE_PREFER_REST=true
   FIRESTORE_LOCAL_FALLBACK=false

   FIREBASE_SERVICE_ACCOUNT_JSON=<paste entire service-account JSON as one line>
     Tip: open the JSON in an editor, minify to one line, paste into Render Secret.

   CORS_ORIGINS=<comma-separated, NO spaces issues if trimmed>
     Start with:
       http://localhost:5174,http://localhost:5173
     After Netlify sites exist, ADD:
       https://YOUR-ERP-SITE.netlify.app,https://YOUR-API-DEMO-SITE.netlify.app
     Then restart/redeploy the Render service.

5. Deploy. Wait until status is Live.

6. Copy the service URL, e.g.:
   https://keiros-erp-api.onrender.com

7. Smoke test in a browser:
   https://keiros-erp-api.onrender.com/api/health
   Expect JSON with ok/health and dataMode.


------------------------------------------------------------------------------
STEP 2 — Deploy ERP on Netlify
------------------------------------------------------------------------------
1. Open https://app.netlify.com → Add new site → Import an existing project
2. Choose GitHub → scsresearch1/Keiros2
3. Configure:
   - Base directory: ERP_Full
   - Build command: (from netlify.toml) npm ci && npm run build
   - Publish directory: dist
4. Site configuration → Environment variables → Add:

   VITE_USE_FIREBASE=true
   VITE_FIREBASE_API_KEY=...
   VITE_FIREBASE_AUTH_DOMAIN=...
   VITE_FIREBASE_PROJECT_ID=...
   VITE_FIREBASE_STORAGE_BUCKET=...
   VITE_FIREBASE_MESSAGING_SENDER_ID=...
   VITE_FIREBASE_APP_ID=...
   VITE_FIREBASE_MEASUREMENT_ID=...   (optional)

5. Deploy site. Copy URL: https://xxxx.netlify.app

6. Smoke test:
   - Open ERP URL
   - Login (Firebase Auth must allow this web domain)
   - Firebase Console → Authentication → Settings → Authorized domains
     → add YOUR-ERP-SITE.netlify.app


------------------------------------------------------------------------------
STEP 3 — Deploy API Demo on Netlify (second site)
------------------------------------------------------------------------------
1. Netlify → Add new site → Import same GitHub repo again
2. Configure:
   - Base directory: API_DEMO
   - Build / publish from netlify.toml
3. Environment variables:

   VITE_API_BASE=https://keiros-erp-api.onrender.com
   (use your real Render URL, no trailing slash)

4. Deploy. Copy URL: https://yyyy.netlify.app

5. IMPORTANT: go back to Render → CORS_ORIGINS and add both Netlify URLs, then redeploy API.


------------------------------------------------------------------------------
STEP 4 — End-to-end smoke test
------------------------------------------------------------------------------
1. API health: GET /api/health on Render → OK
2. ERP Netlify: login works
3. API Demo Netlify:
   - Paste API key (ERP-issued or demo prefix key)
   - Hierarchy dropdowns load
   - Navigate returns map journey
4. ERP → API Logs / API Navigation Live shows the call (if Firestore writable)


------------------------------------------------------------------------------
STEP 5 — Optional hardening
------------------------------------------------------------------------------
- Custom domains on Netlify + Render
- Restrict CORS_ORIGINS to production URLs only (remove *)
- Keep FIRESTORE_LOCAL_FALLBACK=false in real demos
- Free Render sleeps after idle ~15 min; first request may take 30–60s
- Never commit service-account JSON or .env files

================================================================================
PART E — TROUBLESHOOTING
================================================================================

API Demo: "offline" / failed fetch
  - VITE_API_BASE missing or wrong → rebuild Netlify site after fixing
  - CORS blocked → add Netlify origin to Render CORS_ORIGINS and restart
  - Render asleep → wait for cold start, retry

ERP: Firebase auth fails on Netlify
  - Add netlify.app domain under Firebase Auth authorized domains
  - Confirm all VITE_FIREBASE_* were present at BUILD time (Vite inlines them)

API: dataMode local-seed on Render
  - FIREBASE_SERVICE_ACCOUNT_JSON invalid/missing
  - Or Firestore quota → check Firebase console

Build fails on Netlify
  - Base directory wrong (must be ERP_Full or API_DEMO)
  - Node version: netlify.toml sets 22
