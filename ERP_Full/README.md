# Keiros ERP

Main Keiros ERP application (`ERP_Full`).

## Stack

- React 19
- TypeScript
- Vite 8

## Setup

```bash
cd ERP_Full
npm install
npm run dev
```

## Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start development server |
| `npm run build` | Production build         |
| `npm run preview` | Preview production build |
| `npm run lint`  | Run ESLint               |
